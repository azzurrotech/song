Available Routes

GET /_song/health — Health check
GET /_song/silos — List silos
GET /_song/components.js — Web Components runtime
GET /_song/components — Web Component definitions
GET /{silo}/ — Serve static resource
POST /{silo}/ — Upsert static resource

Description

song is a static hosting server with server-side template processing and Web Component support. It serves resources from siloed directories under a root store.

Quick Start

song --port 8080 --root ./data

Then visit http://localhost:8080 to see this dashboard.
