Render playground

Per-silo .song/meta.json: index header rules and template routes.

    Create a silo (form or JSON):
  curl -X POST localhost:8083/api/song/silos -d 'name=demo'         # form
  curl -X POST localhost:8083/api/song/silos -H 'Content-Type: application/json' -d '{"name":"demo"}'

Create a file (form, JSON, or raw body):
  curl -X POST localhost:8083/api/song/silos/demo/file \
       -d 'path=index.html&content=
    hi
    &encrypt=false'

Read:
  curl 'localhost:8083/api/song/silos/demo/file?path=index.html&content=1'

Update:
  curl -X PUT localhost:8083/api/song/silos/demo/file \
       -H 'Content-Type: application/json' -d '{"path":"app.js","content":"console.log(1)","encrypt":true}'

Delete:
  curl -X DELETE 'localhost:8083/api/song/silos/demo/file?path=app.js'

Multipart upload:
  curl -X POST localhost:8083/api/song/silos/demo/upload \
       -F 'dir=assets' -F 'file=@logo.png'

Server-side render (form or JSON):
  curl -X POST localhost:8083/api/song/silos/demo/render \
       -d 'template=page&title=Hello&items=a&items=b'

Serve:  http://localhost:8083/demo/            (index.html by header)
        http://localhost:8083/demo/index.html
Encrypted files decrypt transparently when served.
Magic links: POST /api/auth/generate, /validate, /revoke
